# 酒馆书屋 / ST Nook

Gloria · v2.0.25

[打开在线阅读器](https://st-nook.pages.dev/)

## 本地使用

下载 `index.html`，使用 Edge 打开即可。样式、脚本和图标已嵌入，阅读、编辑、批注和导出无需安装依赖，离线也能使用。

汇文明朝体、霞鹜文楷和霞鹜新致宋通过外部 CSS 按需加载，首次使用需要联网；离线时使用浏览器可用的字体缓存或系统字体。没有内嵌大型字体文件，HTML 小于 1 MB。

“阅读设置”中，点击“正文字体”右侧的“编辑”，输入名称并上传 TTF、OTF、WOFF 或 WOFF2 文件，即可添加并使用字体；已添加的字体也可在这里切换或删除，删除当前字体后自动使用默认宋体。

主题列表最后新增“磨砂 · 自选风景”，日间 / 夜间切换和背景上传按钮位于这张主题卡片的预览图内。没有上传图片时，日间使用白 / 蓝配色，夜间使用黑 / 蓝配色；上传背景后，按钮、强调色和玻璃底色自动跟随图片主色，日间保留白色基底，夜间保留黑色基底。黑白图片使用中性配色，移除背景后恢复默认蓝色。图片配色在本机生成并保存，无需联网。

磨砂界面重新设计了浮动导航、玻璃书籍卡片、分段筛选和设置浮层，使用薄透底色、细边高光和柔和阴影区分层次。阅读界面仍为全屏磨砂，背景图铺满屏幕，正文直接排在柔化后的整层玻璃上。上传的背景会自动适配尺寸，按钮文字根据日间 / 夜间保持对比度。

阅读页和扉页顶部的章节目录、我们的回忆采用与小剧场、字体设置一致的图标按钮。主界面的固定顶栏保留原有底色，使用更强的磨砂模糊，柔化滚动内容的文字和轮廓，日间 / 夜间颜色同步切换。

手机端的目录和回忆窗口会随当前可视区域调整高度，固定标题栏并独立滚动内容；长书名、目录操作、日历和日期输入框按窄屏排布，避免按钮被挤出窗口。

上传的字体和背景图保存在当前浏览器，重新打开后仍可使用，无需联网。这些外观文件不包含在书籍备份中；更换浏览器、阅读器地址或清理站点数据后需要重新上传。

支持聊天记录导入、正则整理、文件排序与衔接预览、滚动与翻页阅读、文字编辑、批注、书摘长图、聊天日历和阅读记录。

聊天记录导入和更新不再限制文件选择器的扩展名，避免 iPhone / iPad 将 JSONL 文件显示为灰色。选中后仍按 JSON / JSONL 内容解析，支持多选导入和单文件更新。

阅读足迹中的排行榜支持楼层 / 章节、正文字数、陪伴时间、粘人、相遇时间和累计阅读时长。点击小图标标签切换榜单，顶部显示当前榜名。快速正则默认留空，“删除 / 只读 / 替换”在手机上同排显示；相同处理方式和内容成功保存超过 3 次后，会出现在“智能读取”下拉列表底部的“常用正则”中，选择即可填入。记录保存在当前浏览器，可跨书籍复用；取消和保存失败不计次。

首次打开书籍时进入扉页，显示大封面、书名和简介；没有图片时显示书名封面。扉页图片右下角的半透明眼睛按钮可全屏查看封面，再次点击眼睛退出，也支持按 Esc 或 APK 返回键退出。已有阅读进度时直接回到上次阅读的位置。扉页作为第 0 章列在普通目录最前面，浏览扉页不会改变已有阅读进度；书架封面使用完整书名，不使用角色卡名称。

书架会记住最后选择的排序方式，重新打开时自动沿用。添加和编辑批注使用同样的单层卡片样式，配色跟随阅读主题；摘录在上、批注在下，两部分各自滚动，批注输入区更紧凑，窗口适配一屏和手机键盘。

正文中的 HTML 音乐播放器支持音频资源与点击交互，兼容原生音频控件和自定义播放器。翻页、切换章节时保留当前播放器，避免歌曲重新加载；播放器离开当前页面后会提供暂停、继续和停止按钮。返回书架时停止播放。歌曲能否加载仍取决于音频链接是否可用及浏览器的网络限制，外部音频需要网络。

书籍内容和统计缓存保存在当前浏览器中，不会写入 HTML 或上传到此仓库。正文字数与“爱你”次数会复用已保存的结果，正文变化后更新相应统计。可导出 TXT 小说或完整备份。

“阅读美化”中的“全部导出备份”可导出所有书籍。通过“新建书籍”→“恢复备份”导入后，先按书籍编号及同名检查重复书籍，逐行选择“覆盖 / 跳过 / 另存”，顶部支持“一键跳过 / 一键覆盖”；这两个按钮只处理重复项，新书自动导入。另存保留原书并建立副本。恢复会保留正文、封面、正则、批注、章节修改和阅读记录，兼容缺少可选字段的旧备份；损坏的书籍单独列出，不影响其他书籍恢复。所选书籍一并写入本地数据库，存储失败时不会只覆盖其中一部分。

已有书籍修改正则、更新聊天文件和编辑章节采用同样的保留条件：在原楼层中仍能明确定位的原片段，继续保留其批注、划线、手动修改和删除；原片段被正则或新聊天移除、替换，或重复文字的位置无法确定时，对应记录暂停应用，不会套到其他同句，也不会把已移除的原文对应的修改插回正文。编辑章节不再清空整章的选中文字修改。更新文件后，已经删除的章节仍保持删除。

在“编辑书籍”中点击“查看待核对记录”，可查看暂停记录的摘录、批注及修改内容，并选择保留备查或移除；根据摘录在正文中重新添加也可以。恢复原文或正则后，可点击“重新核对”，只有重新确认位置的批注与文字修改才会恢复应用。完整备份保留暂停记录及定位信息。旧书进入编辑时自动补充定位信息；如果旧记录已经无法定位，会保留为待核对记录。保存书籍后生效。

## 酒馆插件

独立插件位于 [ST-nook-extension](https://github.com/gloria-yin/ST-nook-extension)，此仓库只存放阅读器 `index.html`、在线离线缓存脚本 `sw.js` 和本说明。

插件可选择聊天、已开启的正则及角色头像，直接选择“复制资料”“下载备份”或“在线导入”，无需选择阅读器类型或先准备资料。回阅读器点击“新建书籍”→“接收书籍”，也可以在书架直接按 Ctrl+V。接收后进入编辑界面，检查后点击“生成书籍”保存。

“在线导入”会打开 https://st-nook.pages.dev/ 并尝试接收剪贴板，沿用该网址的书架。使用本地文件时，请回原 HTML 接收，沿用原文件的书架。聊天资料不写入 HTML 或网址。

“接收书籍”打开后会尝试读取剪贴板。已授予读取权限时，返回阅读器还可自动发现新的书籍资料，弹出接收窗口；同一份资料在当前标签页不会反复提示。浏览器未授权时，可在接收框直接粘贴，或点击“选择导入文件”导入 JSON。无需授予权限也能通过粘贴或文件完成导入。

接收窗口的“粘贴”按钮可主动读取剪贴板，现有 ST Nook Android APK 会优先通过其原生剪贴板接口读取，无需重新安装。也支持系统长按粘贴和输入法粘贴后点击“接收书籍”。插件在手机复制未成功时会保留资料供再次点击复制；资料超过手机剪贴板可靠容量时，请下载 JSON 备份并导入，避免截断。

书籍保存在实际阅读器地址对应的浏览器数据中，不同浏览器和地址分别存储。GitHub Pages、Cloudflare Pages 和本地 HTML 的书架分别保存；从旧网址迁移时，请先导出完整备份，再在新网址恢复。

## 在线离线缓存与更新

`index.html` 会在 HTTPS 在线地址注册同目录的 `sw.js`。首次联网缓存完成后，阅读器可离线打开；“阅读美化”→“离线与更新”显示缓存状态。本地 HTML 不使用 Service Worker，仍可单文件直接打开。

页面优先打开已缓存的版本，联网时在后台检查页面及缓存脚本更新。GitHub 推送经 Cloudflare Pages 部署到在线地址后，新版本会缓存到浏览器并提示；在“阅读美化”中点击“使用新版本”生效。也可点击“检查更新”。当前未保存的编辑需要先保存；更新不会清空书籍、批注、阅读进度或统计。即使只修改 HTML 而未修改 sw.js，也能检查并缓存新版页面。

缓存不是永久保证。浏览器清理、用户删除站点数据或存储空间不足可能移除缓存；程序会尝试申请持久存储，但是否批准由浏览器决定。重要书籍请保留完整备份。离线阅读可不联网；联网检查更新、首次下载字体仍会产生流量。实际加载过的自定义字体样式与字形会按需缓存，尚未加载的字形离线时可能使用系统字体。

## 开发验证

在安装了 Edge 和 Node.js 22 或更新版本的 Windows 上，运行 `node tests/reader-retention.mjs` 验证批注及修改保留，运行 `node tests/reader-appearance.mjs` 验证字体管理、背景持久保存和桌面 / 手机的磨砂阅读布局。可通过 `EDGE_PATH` 指定浏览器，通过 `TEST_FONT_PATH` 指定测试用的字体文件；字体测试默认读取 Windows 自带的 `calibri.ttf`，不将字体打包进仓库。设置 `APPEARANCE_SCREENSHOTS` 可保存外观检查截图。

## 在终端更新 GitHub

在本地阅读器文件夹打开 PowerShell，修改完成后运行：

```powershell
git status
git add -- index.html sw.js README.md
git commit -m "Update ST Nook reader"
git push origin main
```

`git add` 只选择阅读器的这三个文件，不会上传提示词或原始图片。首次推送时若出现登录提示，按 Git Credential Manager 的提示登录 GitHub。运行前先确认当前文件夹是阅读器仓库；如有其他设备修改，先在工作区干净时执行 `git pull --ff-only origin main`。

在线地址是 https://st-nook.pages.dev/ 。Cloudflare Pages 项目需关联 `gloria-yin/ST-nook` 仓库，生产分支选择 `main`，直接发布仓库根目录的静态文件（无需构建命令）。关联后，推送 GitHub 会触发部署；在 Cloudflare 的项目部署记录中确认成功，再到阅读器“阅读美化”→“检查更新”。只推送 GitHub、但 Cloudflare 尚未部署成功时，在线页面不会改变。`sw.js` 必须和 HTML 一起发布并以 JavaScript 类型提供，不能被重定向为 HTML。

酒馆插件使用独立仓库，两个仓库需要分别提交和推送。更新插件时，先进入它在 SillyTavern 的 `data/default-user/extensions/st-nook` 文件夹，再执行：

```powershell
git add -- manifest.json README.md extension
git commit -m "Update ST Nook extension"
git push origin main
```

之后在酒馆扩展管理中更新插件，按 Ctrl+F5 刷新。添加书籍窗口应显示当前插件版本。仅修改本地 HTML 而没有修改插件时，无需推送插件仓库。
