# 酒馆书屋 / ST Nook

Gloria · v2.0.2

[打开阅读器](https://gloria-yin.github.io/ST-nook/)

## 单文件阅读器

下载 `index.html`，使用 Edge 打开即可。CSS、脚本、图标、汇文明朝体、霞鹜文楷和霞鹜新致宋均已嵌入，基础阅读功能可以离线使用。

书籍、聊天内容、封面和批注存储在当前浏览器的 IndexedDB 中；阅读设置和进度存储在 localStorage 中。HTML 和此仓库不包含用户的聊天记录。网页地址和本地 HTML 地址分别保存自己的浏览器数据，可通过完整备份迁移。

## 酒馆插件

下载 [独立插件 ST-Nook-Extension.zip](ST-Nook-Extension.zip)，解压到 SillyTavern 的 `data/default-user/extensions/st-nook` 文件夹。插件不包含阅读器 HTML，也不要求把阅读器复制到插件目录。

刷新酒馆，在角色卡的“管理聊天文件”中，“导入聊天”旁边会出现“添加书籍”。

1. 选择“链接版”或“文件版”。链接版固定使用在线版本；文件版通过按钮选择自己的新版 HTML 文件，并记住选择。
2. 选择当前角色的一份或多份聊天，填写书名。
3. 按组或逐条选择已开启的全局、预设和局部正则，并选择是否使用角色头像。
4. 确认后选择新标签页或独立窗口，自动进入阅读器的“新建书籍”界面。
5. 检查并编辑内容，点击“生成书籍”完成保存。

插件从在线地址加载阅读器或读取所选 HTML，在当前酒馆站点的浏览器环境内打开，避免酒馆的跨窗口隔离切断数据传送。书籍保存在该酒馆站点的浏览器数据中，可通过完整备份搬运到独立网页或本地 HTML。

详见 [插件说明](extension/README.md)。

## 阅读功能

- 多文件 JSONL / JSON 导入、后台分块解析、文件手动排序、首末章快捷预览和双栏衔接对照。
- 可折叠的正则管理，角色卡与预设导入；“本章内容”默认收起，展开后选择章节并切换原文 / 正则后内容。
- 滚动或翻页阅读、章节标题编辑、原始章节编辑、选中文字修改与删除。
- 正文关键词搜索与高亮摘要，划线、批注、原文定位和按书籍筛选摘录。
- 六种阅读主题、五种字体选择、引号斜体及字体、字号和行距设置。
- 八种书摘图片模板、名称替换、完整长图导出；长书摘不分页，无“双栏”模板或“下载全部”按钮。
- 阅读足迹、聊天日历；通过记录标题旁的金牌按钮打开四类排行榜，前三名显示金、银、铜标识。
- TXT 小说和完整备份导出，备份恢复。
- 手机和电脑端点击弹窗、书摘大图预览外部均保持当前界面，使用关闭或取消按钮退出。

聊天日历和楼层数使用全部原始聊天日期与楼层。正文字数、正文搜索及“爱你”次数使用当前正则、阅读设置和文字修改后的正文。字数统一显示为一位小数的万字。统计结果持久保存在浏览器中，内容不变时直接复用；修改某章时只更新受影响章节，收藏和批注不会触发重算。陪伴时间为首次到最后一次聊天的日期跨度。
