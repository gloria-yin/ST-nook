# 酒馆书屋 / ST Nook

Gloria · v2.0.0

[打开阅读器](https://gloria-yin.github.io/ST-nook/)

## 单文件阅读器

下载 `index.html`，使用 Edge 打开即可。CSS、脚本、图标、汇文明朝体、霞鹜文楷和霞鹜新致宋均已嵌入，基础阅读功能可以离线使用。

书籍、聊天内容、封面和批注存储在当前浏览器的 IndexedDB 中；阅读设置和进度存储在 localStorage 中。HTML 和此仓库不包含用户的聊天记录。网页地址和本地 HTML 地址分别保存自己的浏览器数据，可通过完整备份迁移。

## 酒馆插件

在 SillyTavern 的扩展管理中使用此仓库地址安装：

```
https://github.com/gloria-yin/ST-nook
```

刷新酒馆，在角色卡的“管理聊天文件”中，“导入聊天”旁边会出现“添加书籍”。

1. 选择插件内阅读器、仓库网页或自己的新版 HTML 文件。
2. 选择当前角色的一份或多份聊天，填写书名。
3. 按组或逐条选择已开启的全局、预设和局部正则，并选择是否使用角色头像。
4. 点击“确认添加”，阅读器会在新窗口中打开并接收书籍。

选择 HTML 文件时，浏览器通过当前酒馆站点打开所选文件，数据存储在该酒馆站点下。需要浏览器允许酒馆打开新窗口。

## 阅读功能

- 多文件 JSONL / JSON 导入、后台分块解析、文件手动排序和首末章衔接预览。
- 可折叠的正则管理，原文 / 正则后内容对比，角色卡与预设导入。
- 滚动或翻页阅读、章节标题编辑、原始章节编辑、选中文字修改与删除。
- 正文关键词搜索与高亮摘要，划线、批注、原文定位和按书籍筛选摘录。
- 六种阅读主题、五种字体选择、引号斜体及字体、字号和行距设置。
- 九种书摘图片模板，名称替换、长文分页与批量图片输出。
- 阅读足迹、聊天日历、楼层 / 章节榜、正文字数榜、陪伴时间榜和粘人榜。
- TXT 小说和完整备份导出，备份恢复。

聊天日历和楼层数使用全部原始聊天日期与楼层。正文字数、正文搜索及“爱你”次数使用当前正则、阅读设置和文字修改后的正文。陪伴时间为首次到最后一次聊天的日期跨度。
